## 知识点 1：列表 List（有序、可变）

**概念**

用 `[ ]` 表示，元素可重复，支持不同类型混装，可索引可切片。

**常用方法**

- `append(x)` 尾部添加一个元素
- `extend(可迭代对象)` 批量追加多个元素
- `insert(i, x)` 在下标 i 处插入 x
- `remove(x)` 删除第一个值为 x 的元素，不存在会报错
- `pop(i)` 弹出并返回下标 i 处元素，默认最后一个
- `clear()` 清空列表
- `index(x)` 返回 x 第一次出现的下标
- `count(x)` 统计 x 出现的次数
- `sort()` 原地排序，可加 key、reverse 参数
- `reverse()` 原地反转
- `copy()` 浅拷贝

**易错点**

- `remove(x)` 是按值删除，且值不存在会报错，别和按下标操作的 `pop(i)` 弄混

## 知识点 2：元组 Tuple（有序、不可变）

**概念**

用 `( )` 表示，创建后不能增删改，常用于坐标、函数多返回值等固定数据。因为不可变，可以作为字典的键，列表不行。

**常用方法**

- `count(x)` 统计 x 出现的次数
- `index(x)` 返回 x 的下标
- 支持切片、`+` 拼接、`*` 重复
- 拆包写法：`a, b = (1, 2)`

**易错点**

- 元组不可变，所以能当字典的键；列表可变，不能当字典的键

## 知识点 3：集合 Set（无序、不重复）

**概念**

用 `{ }` 表示，但空集合必须写 `set()`，因为 `{}` 是空字典。底层哈希表实现，查找效率高，常用于去重和集合运算。

**常用方法**

- `add(x)` 添加元素
- `remove(x)` 删除元素，不存在会报错
- `discard(x)` 删除元素，不存在也不报错
- `pop()` 随机删除并返回一个元素
- `clear()` 清空
- `union(other)` 或 `|` 求并集
- `intersection(other)` 或 `&` 求交集
- `difference(other)` 或 `-` 求差集
- `symmetric_difference(other)` 或 `^` 求对称差集
- `issubset()` / `issuperset()` 判断子集/超集关系

**易错点**

- 空集合不能写 `{}`（那是空字典），必须写 `set()`
- `remove(x)` 找不到会报错，`discard(x)` 不会报错，`pop()` 是随机删除，不是按值删除

## 知识点 4：字典 Dict（键值对映射）

**概念**

用 `{key: value}` 表示，Python 3.7+ 保证插入顺序，键必须唯一且可哈希，值任意类型，查找效率高。

**常用方法**

- `get(key, default)` 安全取值，key 不存在时返回 default 而不报错
- `keys()` 返回所有键
- `values()` 返回所有值
- `items()` 返回所有 (键, 值) 对
- `update(other)` 用另一个字典/键值对合并更新
- `pop(key)` 删除 key 并返回其值
- `popitem()` 删除并返回最后插入的键值对
- `setdefault(key, default)` key 不存在时设置默认值
- `in` 判断某个键是否存在

**易错点**

- `get(key, default)` 和普通取值 `d[key]` 的区别：key 不存在时，`get` 返回 default（不报错），普通取值会直接抛 `KeyError`
