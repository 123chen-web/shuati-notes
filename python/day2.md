## 知识点 1：基础语法速览（和 C/C++ 的主要区别）

**概念**

Python 用缩进（通常 4 个空格）划分代码块，不用 `{}`；语句不用分号结尾；变量不用声明类型，赋值时自动绑定类型，同一个变量名以后还能绑定别的类型的值。

**和 C/C++ 不同的地方**

- `print(x)` 代替 `cout` / `printf`，可以一次输出多个值；`#` 开头是注释，不是 `//` 或 `/* */`
- 没有 `++`、`--`；`x += 1` 这种复合赋值还在，但自增自减符号没有
- `/` 一律返回浮点数（哪怕是两个整数相除）；整除要用 `//`；乘方是 `**`，不是 `pow()` 或 `^`（`^` 在 Python 里是按位异或）
- `input()` 读进来的永远是字符串，要计算之前得自己用 `int()` / `float()` 转换；`int("3.5")` 直接报错，得先转 `float` 再转 `int`
- `if` / `elif` / `else` 不需要括号包条件，但冒号和缩进不能少；比较运算符和 C 一样，支持连写区间判断，比如 `0 <= x <= 30`
- `for` 循环基本都是"遍历"写法：`for item in items`，配合 `range(start, stop, step)` 模拟 C 的计数循环；`range()` 不包含终点
- `while True:` + `break` 是最常见的"直到满足条件才退出"写法，和 C 差不多，但要注意别忘了在循环体里更新条件变量，否则死循环

**易错点**

- 缩进不一致会直接报错，不是风格问题，是语法错误；中文引号不能代替英文引号
- `=` 是赋值、`==` 是比较，这点和 C 一样，但因为没有类型声明更容易顺手打错
- `-3 // 2` 结果是 `-2`（向负无穷取整，不是向零截断）；`round()` 遇到正好一半的情况会舍入到偶数

## 知识点 2：字符串——切片与格式化（和 C 的字符数组差别很大）

**概念**

Python 字符串是不可变对象：`upper()`、`replace()` 这类方法都返回一个新字符串，不会改原字符串。没有独立的字符类型，单个字符也是长度为 1 的字符串。C 里字符串是以 `\0` 结尾的字符数组，可以直接改某个下标的字符；Python 不行，必须整体重新赋值。

**常用方法/语法**

- `len(s)`、`s[i]` 取下标（`s[-1]` 是最后一个字符，负下标从末尾数）
- `s[start:stop:step]` 切片：`s[:4]` 前 4 个，`s[4:]` 从下标 4 到结尾，`s[-4:]` 最后 4 个，`s[::2]` 隔一个取一个，`s[::-1]` 整体反转——这是 C 里没有的写法，C 要反转字符串得自己写循环
- `s.find(x)` / `s.rfind(x)` 找不到返回 -1；`s.index(x)` 找不到直接报错（和 `find` 的区别要记住）
- `s.upper()` / `s.lower()` / `s.capitalize()`、`s.isdigit()` / `s.isalpha()`、`s.count(x)`、`s.replace(old, new)`、`s.strip()`、`s.split(sep)`、`sep.join(items)`
- f-string 格式化：`f"{price:.2f}"` 保留两位小数，`f"{value:,}"` 加千分位，`f"{n:03d}"` 补零到 3 位，`f"{text:<10}"` / `>10` / `^10` 左中右对齐——这一整套格式说明符在 C 里对应的是 `printf` 的 `%.2f`、`%03d`，但写法完全不同，f-string 是嵌在字符串里的

**易错点**

- 单个下标越界会报错，但切片越界一般不报错、自动截断到实际长度
- `isdigit()` 不是通用的"是不是数字"校验：负号、小数点都会让它返回 `False`
- 格式化只是生成一个新的显示用字符串，不会改变原变量本身

## 知识点 3：条件表达式（三元写法）

**概念**

`真时的值 if 条件 else 假时的值`，对应 C/C++ 的 `条件 ? 真值 : 假值`，只是把条件挪到了中间。比如 `status = "成年" if age >= 18 else "未成年"`。

**易错点**

- 必须有 `else`，不能只写一半；它本身是一个表达式、会产生一个值，不是省略大括号的 if 语句

## 知识点 4：二维容器与"共享引用"陷阱

**概念**

Python 的二维列表就是"列表里套列表"，比如 `grid = [[1, 2], [3, 4]]`，`grid[1][0]` 取第二行第一项。这里最需要注意的是 Python 里普通赋值不是拷贝：把一个列表赋给另一个变量，两个名字指向同一块数据，这和 C 里数组/结构体赋值会整体拷贝的行为不一样（C 里指针才会共享，普通数组赋值是拷贝）。

**易错点**

- `[[0] * 3] * 2` 看起来是造了两行三列的网格，实际上外层的 `* 2` 只是把同一个内层列表的引用复制了两份，改其中一行的一个元素，另一行也会跟着变
- 同理，`key = chars` 之后 `key` 和 `chars` 是同一个列表，想要一份独立副本得显式 `copy()`
- 不同"行"的长度可以不一样，Python 不会像 C 的二维数组那样强制每行等长

## 知识点 5：random 模块

**概念**

先 `import random`，Python 标准库自带的随机数生成器比 C 的 `rand()` 好用一些，不需要自己手动取模映射范围。

**常用函数**

- `random.randint(a, b)` 生成闭区间 `[a, b]` 的随机整数
- `random.randrange(start, stop, step)` 类似 `range()`，不包含 `stop`
- `random.random()` 生成 `[0, 1)` 的随机浮点数
- `random.choice(sequence)` 从非空序列里随机取一个元素
- `random.shuffle(items)` 原地打乱一个可变序列，返回 `None`（不是返回打乱后的新序列）

**易错点**

- `choice()` 不能直接对 `set` 按下标取，因为集合无序、不支持索引
- `shuffle()` 不能直接用在字符串或元组上，因为它们不可变，得先转成列表
