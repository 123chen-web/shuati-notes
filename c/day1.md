## 题目 1：A + B

**标签**：入门、输入输出

**题目描述**

输入两个整数 a 和 b，输出它们的和。

**思路**

最基础的一道题，目的是熟悉这门语言的读入 / 输出写法，不涉及算法逻辑，后面所有题目的代码框架基本都从这里长出来。

**代码**

```cpp
#include <iostream>
using namespace std;

int main() {
    int a, b;
    cin >> a >> b;
    cout << a + b << endl;
    return 0;
}
```

**易错点 / 注意点**

- 如果题目是多组输入，容易忘记用 `while (cin >> a >> b)` 循环读，只处理了第一组数据就结束了
- 数据范围如果可能超过 `int`（比如到 1e10 这种量级），直接用 `int` 相加会溢出，要先看清题目给的数据范围，再决定要不要用 `long long`
