## 题目 1：过马卒（网格路径计数 DP）

**标签**：动态规划、路径计数

**题目描述**

在一个从 (0,0) 到 (n,m) 的网格上，从 (0,0) 出发，每步只能向右或向下走。网格里有一匹马，位于 (mx,my)：马自己所在的格子、以及马一步能跳到的格子都不能经过。求从起点走到终点一共有多少种不同走法。

**思路**

1. 先把马自己所在的格子，以及马一步能跳到的 8 个格子，全部标记为封锁（`bad` 数组），这一步要在递推之前做完。
2. 用二维递推求方案数：`f[i][j]` 表示从起点走到 `(i,j)` 的走法数；起点 `(0,0)` 单独处理（没被封锁就是 1 种走法，否则是 0）；其余格子如果不是封锁点，等于从上面来的方案数 `f[i-1][j]` 加上从左边来的方案数 `f[i][j-1]`。
3. 最终答案是 `f[n][m]`。

**代码**

```cpp
#include<bits/stdc++.h>
using namespace std;

int n, m, mx, my;
long long f[25][25];
bool bad[25][25]; // 标记这个点是不是被封锁(马自己 或 马一步能到的位置)

int dx[9] = {0, -1,-2,-2,-1,1,2,2,1}; // 0是马自己本身，后面8个是马走法
int dy[9] = {0, -2,-1,1,2,-2,-1,1,2};

int main(){
    cin >> n >> m >> mx >> my;

    // 第一步：把马自己和马能攻击到的9个点全部标记为封锁
    for(int i = 0; i < 9; i++){
        int bx = mx + dx[i];
        int by = my + dy[i];
        if(bx >= 0 && bx <= n && by >= 0 && by <= m)
            bad[bx][by] = true;
    }

    // 第二步：递推。f[0][0]是起点，如果起点没被封锁就是1种走法
    if(!bad[0][0]) f[0][0] = 1;

    for(int i = 0; i <= n; i++){
        for(int j = 0; j <= m; j++){
            if(i == 0 && j == 0) continue; // 起点已经单独处理过，跳过
            if(bad[i][j]) continue;        // 封锁点，f保持0，不接受任何转移

            if(i > 0) f[i][j] += f[i-1][j]; // 从上面来
            if(j > 0) f[i][j] += f[i][j-1]; // 从左边来
        }
    }

    cout << f[n][m];
    return 0;
}
```

## 知识点 2：树的遍历（链式前向星存图 + DFS）

**标签**：图论、DFS

**知识点描述**

插入边的时候都插在 `h[a]`（表头）；`ne[i]` 用来把这些边串起来，方便直接遍历一个点的所有出边（`i` 是一条带编号的边）；`e[i]` 记录的是这条边指向的邻居是谁。这套 `h`/`e`/`ne`/`idx` 的写法就是链式前向星，本质是用数组模拟邻接表。

**代码**

```cpp
#include <cstring>
#include <iostream>
#include <algorithm>

using namespace std;

const int N = 100010, M = N * 2;   // M 开两倍：无向图每条边要存两个方向

int n, m;                          // n 个点，m 条边
int h[N], e[M], ne[M], idx;        // 邻接表：h[u]=u 的第一条边编号；e[i]=边 i 指向的点；ne[i]=边 i 的下一条边
bool st[N];                        // st[u]=true 表示点 u 已经被访问过

// 加一条 a -> b 的边：把新边插到 a 的边链表头部
void add(int a, int b)
{
    e[idx] = b;                    // 这条边的终点是 b
    ne[idx] = h[a];                // 新边的 next 指向 a 原来的第一条边
    h[a] = idx ++;                 // a 的表头更新为这条新边
}

// 深度优先搜索：从 u 出发，把 u 能到达的所有点都标记一遍
void dfs(int u)
{
    st[u] = true;                  // 标记一下：u 已经被搜过了（防止重复访问、死循环）

    for (int i = h[u]; i != -1; i = ne[i])   // 遍历 u 的所有出边（沿链表走）
    {
        int j = e[i];              // 边 i 通向的邻居节点
        if (!st[j])                // 这个邻居还没被访问过
            dfs(j);                // 递归进去，继续从 j 往下搜
    }
}

int main()
{
    memset(h, -1, sizeof h);       // 初始化：所有点的边表头都是 -1（表示还没有边）

    cin >> n >> m;                 // 读入点数和边数
    for (int i = 0; i < m; i ++ )
    {
        int a, b;
        cin >> a >> b;
        add(a, b);                 // 加边 a -> b
        add(b, a);                 // 无向图：再加一条 b -> a（有向图就删掉这句）
    }

    dfs(1);                        // 从 1 号点开始遍历（题目保证 1 号点连通时这样写）

    return 0;
}
```
