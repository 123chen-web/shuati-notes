## 题目 1：01 背包 —— P1048 采药

**标签**：动态规划、01 背包

**题目描述**

给定采药总时间 t 和 m 株草药，每株耗时 v[i]、价值 w[i]，每株只能采一次，求在时间限制内能采到的最大价值。

**代码**

```cpp
#include<bits/stdc++.h>
using namespace std;
int t, m;
int v[1010], w[1010];
int dp[1010];

int main(){
    cin >> t >> m;
    for(int i = 0; i < m; i++)
        cin >> v[i] >> w[i];
    for(int i = 0; i < m; i++)
        for(int j = t; j >= v[i]; j--)
            dp[j] = max(dp[j], dp[j - v[i]] + w[i]);
    cout << dp[t];
    return 0;
}
```

**易错点**

- 读入多套了一层循环：一开始写了 `while(m--){ for(i<m) ... }`，导致读入数量翻倍甚至更乱。m 组数据只需要一层 `for` 循环，不要在外面再包一层。
- for 循环条件写成了赋值/判断混淆：`j==t` 和 `j==` —— `=` 是赋值，`==` 是判断相等，自增/自减（`j--` / `j++`）不能留空。
- 多写了一层中括号：`dp[[j-v[i]]+w[i]` —— 写复杂表达式时数一下括号有没有配对。
- 数组大小要跟着数据范围走，不是随便给个整数：`v`、`w` 数组要能装下 m（题目给多大开多大，一般留一点余量）；`dp` 数组要能装下 t（背包容量），不是跟 m 挂钩

## 题目 2：完全背包 —— P1616 疯狂的采药

**标签**：动态规划、完全背包

**题目描述**

和 P1048 采药结构一样：给定总时间 t 和 m 株草药，每株耗时 v[i]、价值 w[i]，但每株可以无限次采摘，求时间限制内能采到的最大价值。

**代码**

```cpp
#include<bits/stdc++.h>
using namespace std;
int m;
long long t;
int v[10010], w[10010];
long long dp[10000010];

int main(){
    cin >> t >> m;
    for(int i = 0; i < m; i++)
        cin >> v[i] >> w[i];
    for(int i = 0; i < m; i++)
        for(int j = v[i]; j <= t; j++)
            dp[j] = max(dp[j], dp[j - v[i]] + w[i]);
    cout << dp[t];
    return 0;
}
```

**易错点**

- 读入循环、`=` / `==`、括号配对、数组开多大这几个坑和「01 背包」一节一样，这里不重复。
- 01 背包 vs 完全背包只差遍历方向：01 逆序（`j` 从大到小），完全正序（`j` 从小到大），状态转移方程本身完全一样。
- P1616 的关键坑：`int` 会溢出。t 最多 10^7，价值最多 10^4，极限情况总价值能到 10^11，远超 int 上限（约 21 亿）。凡是看到数据范围能算出结果可能超过 21 亿，`dp` 和相关变量就要开 `long long`，这次的 `t` 和 `dp` 数组都需要。

## 知识点 3：哈希表（拉链法 + 开放寻址法）

**标签**：数据结构、哈希

**知识点描述**

两种解决哈希冲突的实现方式：拉链法（链地址法，冲突的元素挂成链表）和开放寻址法（线性探测，冲突了就往后找下一个空位）。

**代码**

拉链法：

```cpp
const int N = 100003;
int h[N], e[N], ne[N], idx;

void insert(int x) {
    int k = (x % N + N) % N;
    e[idx] = x, ne[idx] = h[k], h[k] = idx++;
}

bool find(int x) {
    int k = (x % N + N) % N;
    for (int i = h[k]; i != -1; i = ne[i])
        if (e[i] == x) return true;
    return false;
}
```

开放寻址法：

```cpp
const int N = 200003; // 一般开数据范围2~3倍
const int null = 0x3f3f3f3f;
int h[N];

int find(int x) {
    int k = (x % N + N) % N;
    while (h[k] != null && h[k] != x) {
        k++;
        if (k == N) k = 0; // 到头了绕回开头
    }
    return k;
}
```

**易错点**

- 数组要开够大，一般开 100003（十万零三，一个质数，能减少冲突）这个量级，不要开小了
