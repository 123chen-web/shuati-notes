# 刷题记录

记录学习过程：C / C++ 算法刷题的思路与代码、Python 自学笔记，以及按题归档的错题本。

## 怎么用这个站

- 左侧目录按模块分组：**C / C++**、**Python**、**错题本**
- 前两个模块每天一页，结构固定：今日概览 → 逐题的思路 / 代码 / 易错点 → 今日总结
- 错题本一题一页，按「题号-题目名」命名，结构固定：题目来源与链接 → 题目大意 → 我的错误代码 / 思路 → 错误原因分析 → 正确代码 → 关键收获
- 右上角搜索框可以直接搜题目名、标签或代码里的关键词，不用一页页翻

## 新增一天怎么做

1. 在对应模块文件夹下复制上一天的文件，改名成 `dayN.md`（每个模块从 1 开始单独编号）
   - C / C++ 算法内容放在 `c/` 下，例如 `c/day2.md`
   - Python 自学内容放在 `python/` 下，例如 `python/day1.md`
2. 把里面的日期、题目、代码换成当天的内容
3. 打开 `_sidebar.md`，在对应模块下加一行链接指向新文件
4. `git add` / `commit` / `push` 上去，几十秒后网页就更新了

全程不用装任何东西、不用跑任何命令去"生成"网站——改的是什么，网上显示的就是什么。

## 新增一道错题怎么做

1. 在 `cuoti/` 下新建一个文件，文件名统一用「题号-题目名」，例如 `cuoti/B3625-迷宫寻路.md`
2. 照着已有错题页的六段结构写：题目来源与链接 → 题目大意 → 我的错误代码 / 思路 → 错误原因分析 → 正确代码 → 关键收获
3. 打开 `_sidebar.md`，在「错题本」下加一行链接指向新文件
