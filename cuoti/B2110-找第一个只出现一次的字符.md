# B2110 找第一个只出现一次的字符

**标签**：字符串、计数数组、两遍扫描

**记录日期**：2026-09-23

## 题目来源与链接

洛谷 B2110 找第一个只出现一次的字符：https://www.luogu.com.cn/problem/B2110

## 题目大意

给一个只含小写字母的字符串，找出**第一个只出现一次**的字符并输出；如果不存在这样的字符，输出 `no`。

## 我当时的思路（卡住的地方）

这题当时没做出来，没写出能提交的代码。

第一反应是开一个 `bool` 数组标记每个字母"有没有出现过"，扫一遍字符串边扫边标记。很快就卡住了：`bool` 只有 true / false 两种状态，标记完只能回答"这个字母出现过吗"，区分不了"只出现 1 次"和"出现了 2 次以上"——而题目要的恰恰就是这个区别。

## 错误原因分析

卡住的地方其实是两个问题叠在一起：

1. **数据类型选错**：需要的是"出现几次"，`bool` 只能表达"有没有"，信息量不够。把 `bool vis[26]` 换成 `int cnt[26]` 就能记下每个字母出现的次数。
2. **一遍扫描做不到**：扫到某个字符时，只知道它前面出现过几次，不知道后面还会不会再出现，没法当场判断它是不是"只出现一次"。必须先把所有字符的次数完整统计完，再从头扫第二遍。

## 正确代码

两遍扫描 + `int` 计数数组：

```cpp
#include<bits/stdc++.h>
using namespace std;

int main(){
    string s;
    cin>>s;

    int cnt[26]={0};
    for(int i=0;i<s.size();i++)    // 第一遍：统计每个字母出现的次数
        cnt[s[i]-'a']++;

    for(int i=0;i<s.size();i++){   // 第二遍：按原顺序找第一个次数为 1 的
        if(cnt[s[i]-'a']==1){
            cout<<s[i];
            return 0;
        }
    }
    cout<<"no";
    return 0;
}
```

`c-'a'` 是利用 ASCII 里小写字母连续排列的性质，把 `'a'~'z'` 映射成 `0~25` 的数组下标。

## 关键收获

要"出现几次"就别用 `bool`，用 `int` 计数数组；凡是要判断"第一个满足某个全局性质的元素"，都得先统计、再判断，也就是两遍扫描。
