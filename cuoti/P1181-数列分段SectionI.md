# P1181 数列分段 Section I

**标签**：贪心、思路方向错误

**记录日期**：2026-09-23

## 题目来源与链接

洛谷 P1181 数列分段 Section I：https://www.luogu.com.cn/problem/P1181

## 题目大意

给定长度为 N 的正整数数列，要把它分成**连续的**若干段，每段的和不超过 M，求最少能分成多少段。题目保证每个数本身都不超过 M。

## 我的错误代码

```cpp
#include<bits/stdc++.h>
using namespace std;
long long m=0;
int n=0;
int a[100010];
int main(){
    cin>>n>>m;
    int cnt=0;
    for(int i=0;i<n;i++) cin>>a[i];
    sort(a,a+n);
    int r=n-1,l=0;
    while(r>l){
        if(a[r]+a[l]>m){ r--; cnt++; }
        else{ r--; l++; cnt++; }
    }
    if(r==l) cnt++;
    cout<<cnt;
}
```

## 错误原因分析

一看到"分段"就套了"两两配对分组"的模板（就是纪念品分组那一类题）：排序之后左右双指针从两端凑对。

但这题要的是**保持原顺序的连续切割**，`sort` 一上来就把"连续"这个核心约束毁掉了。排完序之后，双指针凑出来的两个数在原数列里根本不相邻，算出来的东西和题目问的已经没有关系了。

这是**算法方向选错**，不是代码细节写错：错误代码本身语法没毛病，调试再久也调不出正确答案。读题的时候得先抓住约束词——"连续"两个字就决定了不能排序，题目要的是在原序列上切刀，不是重新组合元素。

## 正确代码

不排序，按原顺序贪心扫一遍：维护当前段的和 `sum`，能塞进当前段就塞，塞不下就在这里切一刀、新开一段。因为题目保证每个数都不超过 M，每段至少放得下一个数，这样扫一定能走到底。

```cpp
#include<bits/stdc++.h>
using namespace std;
int n=0;
long long m=0;
int a[100010];
int main(){
    cin>>n>>m;
    for(int i=0;i<n;i++) cin>>a[i];

    long long sum=0;   // 当前这一段已经装了多少
    int cnt=1;         // 至少有一段
    for(int i=0;i<n;i++){
        if(sum+a[i]>m){   // 塞不下了，在这里切一刀，a[i] 作为新一段的开头
            cnt++;
            sum=a[i];
        }else{
            sum+=a[i];
        }
    }
    cout<<cnt;
    return 0;
}
```

## 关键收获

看到"分段 / 分组"先分清题目要不要求"连续"：只要带"连续、顺序、原序"这类字眼，`sort` 就是禁手；连续分段求最少段数用贪心——能塞就塞，塞不下就切。
